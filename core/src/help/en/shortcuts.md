# Keyboard shortcuts

> Listed for Windows / Linux. On macOS, `Ctrl` becomes `⌘` and `Alt` becomes `⌥` — the menus already show the translated form.

## File

| Action | Shortcut |
| --- | --- |
| New document (new tab) | `Ctrl+N` |
| New window | `Ctrl+Shift+N` |
| Open file | `Ctrl+O` |
| Open folder as workspace | `Ctrl+Shift+O` |
| Save | `Ctrl+S` |
| Save as | `Ctrl+Shift+S` |
| Close current tab | `Ctrl+W` |
| Close window | Title-bar close button (asks about unsaved work first) |

`Ctrl+Shift+N` and the "windows only" display mode exist on desktop builds only; in a browser or the mobile shell there is no system window to open, so those items are greyed out.

## Editing

| Action | Shortcut |
| --- | --- |
| Undo / redo | `Ctrl+Z` / `Ctrl+Y` |
| Select all | `Ctrl+A` |
| Cut / copy / paste | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` |
| Find and replace | `Ctrl+F` |

## Format

| Action | Shortcut |
| --- | --- |
| Bold | `Ctrl+B` |
| Italic | `Ctrl+I` |
| Strikethrough | `Ctrl+Shift+X` (legacy alias `Alt+Shift+5`) |
| Inline code | `Ctrl+E` |
| Link | `Ctrl+K` |
| Insert image | `Ctrl+Shift+I` |

## Paragraph

| Action | Shortcut |
| --- | --- |
| Heading 1–6 | `Ctrl+1` … `Ctrl+6` |
| Body text | `Ctrl+0` |
| Bullet list | `Ctrl+Shift+]` |
| Ordered list | `Ctrl+Shift+[` |
| Task list | `Ctrl+Shift+9` |
| Blockquote | `Ctrl+Shift+Q` |
| Table | `Ctrl+Shift+T` |
| Code block | `Ctrl+Shift+C` or `Ctrl+Enter` |
| Math block | `Ctrl+Shift+M` |
| Horizontal rule | `Ctrl+Shift+-` |
| Indent / outdent | `Tab` / `Shift+Tab` |

## View

| Action | Shortcut |
| --- | --- |
| Source mode (live preview off) | `Ctrl+/` |
| Focus mode | `F8` |
| Typewriter mode | `F9` |
| Sidebar | `Ctrl+Shift+L` |
| Outline / file tree | `Ctrl+Shift+1` / `Ctrl+Shift+2` |
| Larger / smaller text | `Ctrl+Shift+=` / `Ctrl+-` |
| Actual size (16px) | `Ctrl+Shift+0` |
| System fullscreen | `F11` |

Text size can also be changed with `Ctrl` + mouse wheel; it is written to storage only after scrolling stops, so scrolling never stutters.

## Layout and help

| Action | Shortcut |
| --- | --- |
| Open layout (card output) | `Ctrl+Shift+P` |
| Help | `F1` |

## Platform differences

- **Redo**: `Ctrl+Y` on Windows/Linux, `⌘⇧Z` on macOS — the menu shows the right one.
- **Delete word**: `Ctrl+Del` is `⌥⌫` on macOS.
- Shortcuts are trapped inside dialogs, so `Ctrl+S` while typing a filename does not trigger a save.
