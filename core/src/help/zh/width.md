# 页面显示宽度调整

正文宽度只有一处真源：CSS 变量 `--content-width`。所有调整方式最后都只改这一个值，所以菜单勾选、拖拽、快捷键之间永远不会互相打架。

## 三种调法

**1. 菜单「显示 → 页面宽度」**

| 预设 | 宽度 |
| --- | --- |
| 窄 | 620px |
| 标准 | 860px |
| 宽 | 1080px |
| 铺满 | 不限，跟随窗口 |

**2. 拖右侧把手**

正文右边缘有一条极窄的把手（鼠标移上去会变宽、显示竖向光标）。按住拖动即可连续调整，拖动时右上角显示当前像素值。

- 双击把手：回到标准宽度 860px。
- 取值范围 520 – 1600px，超出会被夹住。

**3. 直接改 CSS 变量**

自动化 / 截图脚本可以往根节点写 `--content-width`，不用接任何接口。

## 三个容易混淆的宽度

| 名称 | 影响什么 |
| --- | --- |
| 页面宽度（本篇） | 正文栏宽，存在本地，跟着这台机器走 |
| 字号 | `--content-font-size`，`Ctrl+滚轮` / `Ctrl+Shift+=` / `Ctrl+-` |
| 排版尺寸 | 导出卡片的画布尺寸（如 9:16、A4），与屏幕上的栏宽无关 |

改屏幕宽度**不会**改导出结果 —— 导出按模板自己的尺寸重新测量分页。

## 窄屏与手机

- 窗口宽度 ≤ 860px 时侧栏自动收起、标签栏隐藏，正文栏宽跟随视口（`--content-width` 不再撑开）。
- 手机竖屏下左右留白自动收窄，拖拽把手隐藏（触摸屏上横向拖动会和滚动抢手势）。
