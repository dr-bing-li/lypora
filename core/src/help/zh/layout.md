# 排版输出

「排版」（`Ctrl+Shift+P`，或菜单栏的「排版」）把当前文档变成适合阅读和分享的卡片：小红书长图、公众号配图、A4 打印稿都走这一条管线。

## 界面

打开后占满整个编辑区（菜单栏保留），从左到右三块：

1. **预览** —— 与导出结果是同一条渲染管线的产物，不是"另画一套好看的 DOM"。
2. **模板画廊** —— 29 套内置模板 + 你自己存的模板，3 列横向大卡，缩略图就是真排版。
3. **参数** —— 颜色、字号、留白、装饰等 44 项，分 11 组（分级标题与贴纸按需展开）。

`Esc` 或右上角关闭返回编辑。参数改完会自动重排（约 160ms 防抖），拖滑块不会卡。

## 模板

- 内置 **29 套**，每套一个四字名（素笺清墨 / 铅字排印 / 夜阑星垂 / 朱线蓝格 …），基调覆盖简约、报刊杂志、手账拼贴、霓虹与胶片。
- 画廊里的缩略图是**这套模板真的排一张卡**，不是色块、也不是截图缓存 —— 换语言时名字跟着变，缩略图里的字体、引文框、印章也跟着换。
- **存为我的模板**：当前参数组合 + 自定义名称，会出现在画廊「我的模板」里，最多 40 个。
- **导出 / 导入样式包**：见下面「样式包」一节。
- 导入同名模板不会覆盖内置的，会加后缀。

## 参数（44 项 / 11 组）

| 分组 | 项 |
| --- | --- |
| 颜色 | 纸色、正文色、次级色、强调色、代码底、引文底、引文线 |
| 度量 | 正文字号、行距、标题字号、左右留白、圆角 |
| 开关 | 页眉细线、页码 |
| 背景 | 底纹预设（无 / 牛皮 / 横线 / 方格 / 点阵 / 水彩 / 纸纹 / 网格 / 齿孔）或上传图片、不透明度 |
| 排版风格 | 引用框 5 式、项目符号 6 式、标题装饰 5 式、外边框 5 式 |
| 印章 | 开关、4 枚预设（朱文圆印 / 白文方印 / 长条 / 手写签名）、位置（四角）、大小 |
| 页眉页脚 | 页眉左、页眉右、页脚三处自由文本 |
| 外带与内面板 | 带宽度、面板底色（可为空）、描边、圆角、阴影形态、内边距 |
| 分隔线 | 细线 / 虚线 / 斜纹 / 胶带 / 无，配高度、双色、角度 |
| 表·码·图 | 表格与代码块各 3 态，图片 3 态（平铺 / 相框 / 胶带） |
| 有序序号 | 纯数字 / 圆形徽标 / 方形徽标 |
| 分级标题 | h1–h4 各一套：底色、字色、内外边距、圆角、旋转、投影、下划线、对齐、行内收窄 |
| 贴纸 | 形状、四角位置、尺寸、旋转、填充、描边、文字、出血量，最多 6 枚 |
| 配色变体 | 只有带变体的模板才有（如波普撞印的粉蓝 / 薄荷 / 紫夜） |

**页眉页脚支持占位符**：`{doc}` 文档名、`{sec}` 当前小节标题、`{date}` 当天日期、`{page}` 页码、`{total}` 总页数。留空就不显示。

比如页脚写 `{doc} · {page}/{total}`，导出的每页底下就是「文件名 · 3/8」。

**注意：模板只能改变量，不能改盒模型。** 一旦允许模板改 `display/width/padding`，分页测量的基准就会漂，屏幕预览和导出结果就会对不上 —— 所以参数表里没有这些。

## 装饰

- **装订**：无 / 线圈 / 回形针 / 订书钉。后两者是真的 SVG 线材与金属带，别在纸张上沿。
- **角处理**：不处理 / 折角 / 圆切角。圆切角在此之上再加 16px 半径，和「圆角」滑块叠加生效。
- **印章**：4 枚预设是 CSS 画的（朱文圆印双环外框、白文方印竖排、长条、手写签名）；也可以上传**透明 PNG**，按原比例缩放进指定大小。大小与四角位置都可调。
- **胶带 / 强调位 / 封面装饰**：模板自带的小配件，开关即可。

## 艺术层（0.13.0）

「波普撞印」这类模板靠的不是新颜色，而是六层结构。参数面板里对应四组：

- **外带（band）** —— 卡片最外圈那层彩色边。它不是 `border`，是 `.ly-card` 的内边距 + 纸色；
  所以调「带宽度」时面板会跟着缩，不是加一条线。
- **内面板（panel）** —— 白卡那一层：底色、描边、圆角、内边距，以及**阴影形态**
  （无 / 贴纸硬阴影 / 软阴影）。硬阴影是 `10px 10px 0`，模糊半径为 0 —— 那是"贴纸感"的定义特征，
  一旦有模糊就变成普通的投影。
- **分级标题** —— h1 到 h4 各一套参数，可以各自是色块、斜纹下划线、行内收窄（色块只有文字那么宽）、
  旋转 ±3°、描边投影。默认都是"不画"，所以老模板不受影响。
- **分隔线** —— `---` 画成细线 / 虚线 / 斜纹 / 胶带；斜纹可以双色加角度。
- **贴纸** —— 最多 6 枚，形状可选五角星 / 四角星 / 爆炸 / 徽标 / 圆斑；从四角定位，
  「出血量」控制它伸出卡片边缘多少。徽标形状可以把「描边色」当文字色用（`POP!` 那一枚）。
- **配色变体** —— 一键换整套颜色（纸色 / 纹理色 / 强调色）。**变体是"就地改色"**，
  点完等于把这些颜色写进当前模板，之后想回去点「恢复默认」。

这些同样只输出 CSS 变量与 `data-*`，没有一处允许模板写任意 CSS —— 样式包因此无法注入样式，
也不会出现"装了别人模板、界面被改花"这种事。

## 尺寸与分页

| 尺寸 | 画布 | 出图 |
| --- | --- | --- |
| 竖版 3:4 | 540 × 720 | 1080 × 1440 |
| 方版 1:1 | 540 × 540 | 1080 × 1080 |
| 长竖 9:16 | 540 × 960 | 1080 × 1920 |
| A4 纸 | 595 × 842 | 1190 × 1684 |

分页三种：

- **自动**：按内容高度切，尽量填满每页。
- **按分隔线**：遇到 `---` 强制换页，适合控制节奏。
- **不分页**：一整张长图。

## 样式包（.zip）

「导出样式包」给你一个 `.zip`，里面就是一套模板的全部：

```
template.json   模板本体（颜色、度量、装饰、字体全在里面）
bg.png          背景图（用到了才有）
stamp.png       印章图（上传过透明 PNG 才有）
README.txt      给接手的人看的说明
```

`template.json` 里图片写成 `"bgImage": "@bg.png"` 这种相对引用，所以整个包可以拷到别的机器、发给别人，解压出来还是同一套东西。

- **下载范例包**：面板里点一下，得到 `sample-ink.zip`（水墨氤氲）。照着改最快 —— 把 `template.json` 里的颜色和 `name` 改掉，重新压回 zip 就能导入。
- **旧版单文件 `.lyt.json` 继续能导入**，只是没有独立图片文件（图以 data URL 内嵌在 json 里）。
- 导入全部在本机解析，不发任何请求。

## 导出

| 格式 | 用途 |
| --- | --- |
| PNG（逐页） | 直接发社交平台 |
| PDF（多页） | 打印 / 存档 |
| ZIP | 一次拿到全部 PNG |
| 复制 | 直接把当前页放进剪贴板 |

导出与预览用的是同一个渲染函数、同一个尺寸和缩放比例，所以"预览是什么样，导出就是什么样"。

## 与界面主题的关系

排版模板有自己的颜色变量，**与界面主题解耦**：界面用 Night 深色，导出照样可以是米白纸张。
