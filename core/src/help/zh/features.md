# 特色功能

Lypora 是一个「源码即真源」的即时渲染 Markdown 编辑器：你看到的排版是装饰出来的，文件本身始终是纯 Markdown，没有任何私有格式。

## 实时预览

- 输入 `**粗体**` 时，符号在光标离开后隐去，只留粗体效果；光标移回该行又还原成源码。
- 结构不变：标题、列表、引用、代码块、表格、公式都已支持。
- 需要看原始文本时按 `Ctrl+/` 切到源码模式，装饰层整体关闭 —— 同一个文件、同一个位置，没有"另存一份"。

## 多文档：标签与多窗口

- **标签**：打开多个文件时在菜单栏下方出现标签栏，每个标签独立保存撤销历史、光标位置和滚动位置，来回切换不丢。
- **多窗口**：「设置 → 显示模式」可选「仅标签 / 仅多窗口 / 两者并存」。仅多窗口下点打开文件会新开一个窗口，适合把两篇稿子拖到两块屏上对照。
- 未保存的标签标题后带 `*`，文件树、最近文件、窗口标题也会同步标出。

## 大纲与文件树

- 左侧栏三个视图：大纲、文件树、最近文件。
- 大纲按标题层级生成，点一条即跳转；滚动正文时高亮跟随。
- 打开文件夹后，文件树只列 Markdown 与纯文本，双击打开为标签。

## 专注与打字机

- **专注模式**（`F8`）：淡化非当前段落。
- **打字机模式**（`F9`）：光标始终保持在视口纵向中部。

## 公式、表格与代码

- 行内公式 `$...$`、公式块 `$$...$$` 由 KaTeX 渲染。
- 表格支持在正文里拖列宽（宽度会写回 Markdown 的分隔行，不引入额外标记）。
- 代码块按语言的语法高亮，语言名写在开栅栏后即可。

## 导出

- **Markdown**：原样导出，不做任何改写。
- **HTML**：单文件，样式内联，离线可看、可直接发给别人。
- **PDF**：桌面版走系统打印管线。
- **长图 / 卡片**：见「排版输出」一篇，可以把文章切成适合手机阅读的图片或 PDF。

## 离线与跨平台

- 桌面端（Windows / macOS / Linux）、Android、以及浏览器直接打开，三处共用同一套前端代码。
- 浏览器与 PWA 下按需缓存，断网可用；文件读写按环境自动降级（本地文件系统 → 文件选择器 → 下载）。
- 界面文案 7 种语言：简体中文、English、日本語、한국어、Español、Français、Deutsch。

## 数据落在哪

- 编辑中的草稿每 4 秒写一次浏览器本地数据库（IndexedDB），用于「最近文件」恢复 —— **它不是你的磁盘文件**。
- 真正落盘只有两个时机：`Ctrl+S` 保存、以及关窗/关标签时在确认框里选「保存」。
