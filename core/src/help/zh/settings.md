# 设置项说明

「设置」菜单里的东西都只影响**这台机器**，不写进文档，也不会跟着文件走。

## 显示模式

多文档的呈现方式，三态：

| 选项 | 行为 |
| --- | --- |
| 仅标签 | 打开文件进新标签，不显示"新建窗口" |
| 仅多窗口 | 打开文件新开一个窗口，标签栏隐藏（已有标签不销毁） |
| 两者并存 | 默认。标签栏 + 可手动新建窗口 |

浏览器与手机壳里没有真正的系统窗口，「仅多窗口」「两者并存」会置灰 —— 置灰比隐藏好，至少能看见为什么不能用。

## 语言

- **跟随系统**：按操作系统语言选，识别不到就用英文。
- 七种语言：简体中文、English、日本語、한국어、Español、Français、Deutsch。
- 语言名一律用母语写（`Français` 而不是"法语"），否则换错语言就找不回来了。
- 切换语言不重建编辑器：文档、撤销历史、光标都在原地，只有界面文案和帮助正文换掉。

## 图片引用

| 设置 | 取值 | 说明 |
| --- | --- | --- |
| 引用方式 | 文件引用 / 内嵌 Base64 | 选内嵌后，下面的路径策略整段失效 |
| 路径策略 | 复制到附件目录 / 相对路径 / 绝对路径 | 详见「图片引用方法」 |

## 不在设置里的偏好

这些也在本地存着，但入口放在各自该在的地方：

- **主题**：菜单「主题」。
- **字号**：`Ctrl+滚轮` 或「显示 → 放大/缩小」。
- **页面宽度**：菜单「显示 → 页面宽度」，或直接拖正文右边缘的把手。
- **排版参数**：排版界面里改，模板另存时一起带走。

## 重置

设置项没有"全部恢复默认"的按钮 —— 需要时逐项改回去即可。以下键可以手动清：浏览器开发者工具 → Application → Local Storage，删掉 `lypora:` 开头的键（**会同时清掉自定义主题与最近文件的设置**，不会动你的 .md 文件）。
