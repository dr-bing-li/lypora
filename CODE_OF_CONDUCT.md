# Code of Conduct

This is a small project with one maintainer and no budget. The rules are correspondingly short.

## Expected behaviour

- **Argue about code, not people.** Disagree with a decision, a design, or a commit as hard as you like; do not
  attack the person who made it.
- **Assume the other side is trying.** Most "obviously wrong" code here was written quickly by someone (or
  something) doing their best under time pressure.
- **Keep it on topic.** Issues and PRs are for this project. Political, religious and off-topic threads will be
  closed without discussion.
- **Respect licences and authorship.** Do not ask for, or submit, third-party theme files, icons, fonts or code
  that this project has no right to redistribute.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language (on the basis of gender, gender identity, sexual
orientation, disability, ethnicity, nationality, age, religion or appearance), sexualised content, doxxing,
deliberate intimidation, and sustained disruption of discussions. Spam, AI-generated issue floods, and
"this project is worthless" threads that offer no reproducible detail also fall under disruption.

## Scope

Applies to issues, pull requests, commit messages, and any space where you are representing this project.

## Enforcement

Report a problem by opening an issue marked `[conduct]` — if the report itself is sensitive, email the address
on the maintainer's GitHub profile instead. The maintainer will read it, respond once, and act. Actions, in
increasing order: a warning; editing or hiding a comment; locking a thread; a temporary block; a permanent
block. There is no committee, no appeal process and no time commitment implied — this is a hobby project, and
the maintainer's judgement is final.

# 行为准则（中文）

这是一个只有一位维护者、没有预算的小项目，规则也相应简短。

**应当做的**：就事论事地争论代码与设计；默认对方是善意的；只谈本项目的事，政治、宗教与跑题话题会被
直接关闭；尊重许可证与他人署名——不要索取或提交本项目无权转分发的第三方主题、图标、字体或代码。

**不可接受的**：骚扰、人身攻击、基于性别 / 性别认同 / 性取向 / 残障 / 族裔 / 国籍 / 年龄 / 宗教 / 外貌的
歧视性言论、色情内容、人肉与曝光隐私、蓄意的恐吓，以及持续扰乱讨论（含垃圾信息、AI 批量灌 issue、
以及不提供任何可复现细节的"这项目一无是处"式发言）。

**适用范围**：issue、pull request、提交信息，以及你代表本项目的任何场合。

**执行**：开一个带 `[conduct]` 标记的 issue 报告；若内容敏感，改发维护者 GitHub 主页上的邮箱。处理措施
由轻到重为：提醒、编辑或隐藏评论、锁定讨论、临时封禁、永久封禁。没有委员会，没有申诉流程，也不承诺
处理时限——这是业余项目，维护者的判断为准。
