## 安装方式

### Windows 10/11 x64

1. 解压 `Lypora-0.4.0-win-x64.zip`，得到 `Lypora\` 文件夹（**保持文件夹结构完整**，不要只拷 exe）。
2. 双击 `Lypora\Lypora.exe`。
3. 首次运行若出现 SmartScreen 提示：点「更多信息」→「仍要运行」。exe **未做代码签名**，这是原因。
4. 想用「打开方式」关联 `.md`：右键任意 `.md` → 打开方式 → 选择其他应用 → 浏览到 `Lypora.exe` → 勾选「始终使用此应用」。
5. 卸载 = 删除该文件夹；配置在 `%APPDATA%\lypora-desktop`，可一并删除。

### Android 10 及以上

1. 把 `Lypora-0.4.0-android.apk` 传到手机（数据线 / 微信文件传输助手 / 网盘均可）。
2. 点开安装。系统会提示「未知来源应用」——这是侧载 APK 的正常提示，在弹窗里允许该来源即可。
   （或用电脑：`adb install -r Lypora-0.4.0-android.apk`）
3. 首次启动约 1–2 秒加载 WebView 内核，随后进入编辑器。
4. 卸载会**一并删除**应用内的文档，卸载前先把要留的文件用分享面板导出去。

## 使用注意事项

**通用**

- 没有自动更新。升级 = 下载新版覆盖（Windows 覆盖文件夹，Android 直接装同签名新版即可覆盖）。
- 项目是 **vibe coding** 产物：功能覆盖广，代码一致性一般，请当草稿看；遇到问题开 issue。
- 超大文档（>1 MB 或数万行）滚动可能掉帧；导出 HTML 的图片仍是相对路径，挪走 HTML 会断图。

**Windows 专属**

- 未签名，SmartScreen 会拦一次；企业环境可能被组策略直接阻止。
- 无安装程序、无注册表写入、无需管理员权限。

**Android 专属**

- **文件存在应用专属目录**：`Android/data/app.lypora.editor/files/Documents/Lypora/`。
  这个目录不需要任何存储权限，但 Android 11+ 的文件管理器看不进去；要交给别人（存到「文件」、发微信、传网盘）
  请用应用内的**导出 → 系统分享面板**。
- 首次点「打开」调用的是系统文件选择器，可以读手机任意位置的文件；保存则写回上面的应用目录。
- 触屏版是另一套外壳，不是把桌面布局压窄：底部两行操作栏（格式化条 + 打开/保存/大纲/导出/主题/菜单），
  顶部 7 个菜单收进底部面板，左侧栏变成抽屉。
- 以下功能在手机上**置灰不可用**（Android WebView 上不可靠）：导出 PDF（请先导出 HTML）、打开文件夹、导入第三方主题 CSS。
- 这一版**没有在真机上做过冷启动、原生文件读写、分享面板的实测**（构建环境里没有连接设备）。
  布局与点击区是用 Chromium 按 360/393/430/800/1440 五档视口 + 触摸模拟验的；真机若遇到问题请开 issue 附机型与系统版本。

## Installation

### Windows 10/11 x64

1. Unzip `Lypora-0.4.0-win-x64.zip` to get the `Lypora\` folder (**keep the folder structure intact** — don't copy the exe alone).
2. Double-click `Lypora\Lypora.exe`.
3. If SmartScreen appears on first run, click "More info" → "Run anyway". The executable is **not code-signed**, which is why.
4. To associate `.md` files: right-click any `.md` → Open with → Choose another app → browse to `Lypora.exe` → tick "Always use this app".
5. To uninstall, delete the folder. Settings live in `%APPDATA%\lypora-desktop` and can be removed too.

### Android 10 and later

1. Copy `Lypora-0.4.0-android.apk` to the phone (USB cable, a file-transfer chat, or cloud storage all work).
2. Tap it to install. Android will warn about apps from unknown sources — that is the normal sideload prompt; allow that source in the dialog.
   (Or from a computer: `adb install -r Lypora-0.4.0-android.apk`)
3. The first launch spends 1–2 seconds loading the WebView runtime, then the editor appears.
4. Uninstalling **deletes the documents stored inside the app**. Use the share sheet to export anything you want to keep first.

## Notes and caveats

**General**

- There is no auto-update. Upgrading means downloading the newer build over this one (replace the Windows folder, or just install the newer APK over the old one — same signature required).
- This is a **vibe-coded** project: broad feature coverage, uneven code consistency. Treat it as a draft, and open an issue when something breaks.
- Very large documents (>1 MB or tens of thousands of lines) may drop frames while scrolling. Images in exported HTML are still relative paths, so moving the HTML breaks them.

**Windows only**

- Unsigned, so SmartScreen blocks once; corporate group policy may block it outright.
- No installer, no registry writes, no admin rights.

**Android only**

- **Files live in the app-specific directory**: `Android/data/app.lypora.editor/files/Documents/Lypora/`.
  This needs no storage permission, but Android 11+ file managers cannot browse into it. To hand a file to another app or person (save to Files, send via a chat app, upload), use **Export → system share sheet** inside Lypora.
- "Open" launches the system file picker and can read files anywhere on the device; saving writes back into the app directory above.
- The touch build is a separate shell, not a squeezed-down desktop layout: a two-row bottom dock (format bar plus Open / Save / Outline / Export / Theme / Menu), the seven top menus folded into a bottom sheet, and the sidebar turned into a drawer.
- These are **greyed out on Android** because they are unreliable inside a WebView: export to PDF (export HTML instead), open a folder, import a third-party theme CSS.
- This build has **not been exercised on a physical device** for cold start, native file IO, or the share sheet — no device was attached to the build machine. Layout and tap targets were verified in Chromium at five viewports (360/393/430/800/1440) with touch emulation. If it misbehaves on your phone, please open an issue with the model and OS version.
