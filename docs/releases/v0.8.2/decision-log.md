# v0.8.2 决策记录

日期：2026-11-09 · 前置版本：v0.8.1（同日发布）

## 为什么要换一个全新的标志

旧标志是蓝色渐变圆角方块 + 三条白色横杠——它从来不是"设计"，只是 `npx cap add android` 之后需要一套
不属于 Capacitor 的占位图时，最容易用 Pillow 画出来、且在任何尺寸下都不会崩的形状。

这一版换成兵马俑宇航员。选它的理由不是"好看"，而是它同时说清了两件事：

1. **继承与向前不冲突**：同一张脸在俑坑里躺了 2200 年，现在穿着压力服在近地轨道。脸没变，环境变了。
2. **跟这个项目有关**：秦并六国推的那套"器"——书同文、车同轨、统一度量衡——本质是**让信息在不同系统
   之间可读**。纯文本是书写史上最成功的那个标准，Markdown 编辑器的全部存在理由就是这个。

历史意涵的完整叙述（含《礼记》「天下大同」出处）写在 README 的「关于这个标志 / The mark」一节，中英双语。

## 关键取舍

### 1. 为什么改成"单源派生"，而不是继续每端一套

旧结构：`core/public/icons/*.png` 给 Web，`desktop/icon.ico` 给 Windows，`res/mipmap-*/` 给 Android，
macOS 和 Linux 再从 `icon-512.png` 现算。也就是说同一个标志在仓库里存了 **三套原始素材 + 两处派生逻辑**
（`gen-android-assets.py` 一套，`_packlib.make_pngs()` 一套）。

改一次 logo 要动五个地方，而且 `gen-android-assets.py` 是靠**解析旧图的白色横条坐标**来重排的——换图之后它
直接报"源图里没找到白色横条"。这不是"忘了同步"，是结构上必然漏。

新结构：`docs/images/logo-source.jpg` 是唯一真源，`tools/gen-icons.py` 一次算完全部 40 多个文件。
`gen-android-assets.py` 降级成 3 行转发壳，文档里的旧命令还能跑。

### 2. 为什么裁头肩特写，而不是整幅

图标的第一约束是 **32px 下认得出**。整幅缩到 32px 只剩一团色块，护目镜和胡须全糊；700px 方框裁到
`(55,5)-(755,705)` 再放大到 1024，24px 下还能认出脸。

代价是丢了画面左右两侧的肩甲和左下角的完整躯干，但保留了右上角的星野——"在太空里"这个语境不能丢，
否则就只是一张古人画像。

### 3. 为什么 Windows 的 ICO 要手写

`Image.save('x.ico', sizes=[...])` 只会缩一张原图，小尺寸由 Pillow 内部再插值，结果 16/24/32px 全是糊的。
ICO 容器本身是 6 字节头 + 每帧 16 字节目录项，写起来比调试 Pillow 的行为快。七档各自 `LANCZOS` 缩放，
≤64px 再叠一层 `UnsharpMask(percent 70)`。

验证方式也跟着定死：打完包，把每一帧的中间 48 字节拿去 `Lypora.exe` 里 `find()`。七帧全中才叫"写进去了"，
而不是"rcedit 返回 0"。

### 4. 为什么 Android 自适应前景满铺不留边

自适应图标的安全区是 108dp 网格中间的 72dp。传统做法是让画面落在安全区内、四周留透明——那是给矢量图标
用的。照片型图标留边，在圆形遮罩下会露出一圈背景色，看起来像图标被裁掉了一圈。

所以前景满铺，代价是圆形遮罩会切掉四角（盔沿和肩线），但脸在正中，切不到。

背景随之从线性渐变改成纯色 `#293542`。取色规则：源图外圈像素按亮度排序取 20% 分位。用中位色会得到
`#743C29`（外圈一半是锈红铠甲），拿去当启动图背景像块铁锈。

### 5. 为什么不做 PNG 量化

`icon-512.png` 481 KB，整套 640 KB，APK 从 10.6 涨到 13.7 MiB。量化能砍到 125 KB（96 色），但对比图里
眼睛那两团橙色发光被压成了砖红；256 色（169 KB）仍然掉饱和。

**眼睛是这个标志的记忆点**，为了 350 KB 把它压掉不值。APK 从 10.6 到 13.7 MiB 也没到需要在意的量级。

### 6. 为什么顺带改 README 的围栏

英文快速开始少了开头围栏，`### Deployment` 连同下面几行一直被渲染成代码块（43 个围栏是奇数）。既然这版
本来就要动 README 顶部，一并修掉，并补回缺失的 `# 1. build the core`。

## 没做的事

- **没有真机验证 Android 图标在启动器里的实际渲染**（只解包核对了 APK 内资源）。
- **没有在 macOS / Linux 真机上启动过**，icns 与 hicolor 只有静态证据。
- **没有为 32px 单独设计简化图形**。照片型 favicon 在标签栏只能认出"有个人"，认不出细节；要做更好的
  小尺寸辨识度，需要另画一版单色/简化标志，属于下一次设计任务。
