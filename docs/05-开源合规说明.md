## 0. 结论

可以以 MIT 公开，且比多数同类项目干净：**运行期依赖全部 MIT，仓库内不含任何第三方主题、字体、图标或截图素材，
文档与代码里不出现第三方产品名**。

公开前必须完成的 5 项处置已全部执行（见 §3），剩余 3 项是**低风险但需要知情**的遗留（见 §4）。

## 1. 许可证兼容性

本项目 outbound 用 MIT（最宽松：允许商用、闭源再分发、修改，仅要求保留版权与许可声明）。

| 组件 | 许可证 | 与 MIT outbound 是否兼容 | 义务 |
|---|---|---|---|
| CodeMirror 6 / Lezer / KaTeX | MIT | ✅ | 保留其版权声明（`node_modules` 内自带，`THIRD-PARTY-NOTICES.md` 已列明） |
| Electron | MIT | ✅ | 同上；分发物内含 Chromium 许可清单，须随包保留 |
| Chromium（Electron 内嵌） | BSD-3 / MIT / Apache-2.0 等 | ✅ | 保留 `LICENSES.chromium.html`，不得删除 |
| TypeScript / playwright-core | Apache-2.0 | ✅（仅构建期） | 若分发其二进制需附 NOTICE；本项目只在构建时调用，不进入产物 |
| lightningcss | MPL-2.0 | ✅（仅构建期） | MPL 是**文件级** copyleft：只在分发 lightningcss 本体时才需开源其文件；其输出的 CSS 文本不受影响 |
| 系统字体 / 本机字体 | 各自许可证 | — | 项目不打包字体；导出的 PDF 由 Chromium 嵌入本机字体子集 |

结论：**没有 GPL/AGPL 类传染性依赖**，MIT outbound 无冲突。

## 4. 遗留引用（可保留，但要知情）

| 位置 | 残留内容 | 为什么保留 | 风险 |
|---|---|---|---|
| `core/src/io/store.ts:80,84` | `typorax`（旧存储前缀） | 迁移逻辑必须知道旧键名 | 无（只是字符串常量，不构成商标使用） |
| `core/src/ui/theme-adapter.ts:127,150,396` | `'typora-export'` / `'typora-sidebar'` / `'typora-source'` | 这是**对方 DOM 的 id 字面量**，用来在用户提供的主题 CSS 里匹配；改名等于主题兼容失效，属互操作性必需 | 低（叙述性使用，且不指向商品来源） |
| `core/src/ui/theme-adapter.ts:6` | 注释解释了上面三个字面量的来历 | 防止后人误改 | 无 |
| `.gitignore` / `docs/internal/` | 内部资料仍在**本机** | 保留复查价值 | 只要不 `git add -f` 就不会公开；推送前请 `git status` 复核 |
| 内置主题名 | `Github`/`Night`/`Vue` 等通用词 | 用户认知成本 | 低（通用词，且不暗示关联） |

如追求"零字面量"，可把主题选择器映射改为外部配置文件（不影响功能），但会失去对存量主题的即插即用——不建议。

## 6. 免责与边界

- 本文是基于公开信息的工程自查，**不构成法律意见**。涉及跨境分发（Google Play / Microsoft Store）时，
  建议就商标与外观相似性做一次正式检索（例如 CNIPA 商标库 + 目标法域的 trade dress 判例）。

  自绘图标、自写主题、自定配色分区、不在 README 做"替代品/克隆"式宣传。
